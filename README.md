# Рыба и крабы

Икра и морепродукты в Москве. Рабочий сайт: https://anton-gorokhovatsky.github.io/rybikraby/

Статический сайт без сборочных зависимостей. Открыть локально:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Публикация в GitHub Pages выполняется после push в `main`. Workflow проверяет
JavaScript и передаёт только файлы сайта. `version.json` на сайте содержит SHA
опубликованного коммита. Для сравнения палитр: `?light=day` и `?light=evening`.

Фотографии и видео — из публичного Telegram-канала «Рыба и крабы»
и сохранённых личных историй Юры, отобранных с разрешения пользователя;
происхождение указано в `assets/sources.json` и `assets/dialogue/sources.json`.
Видео включается посетителем, до нажатия загружается только постер.
Наличие, фасовку, цену и доставку подтверждает Юра при обращении.

Меню остаётся доступным при прокрутке и подстраивает контраст под фон раздела.
На телефоне навигация занимает одну строку. Крупный заголовок Oks объединяет
первый экран; товарный ряд сгруппирован выравниванием и интервалами.
Первый экран занимает высоту окна. Диалоговая версия связывает сравнение
трёх видов икры, разделку рыбы, морепродукты, готовку и прямой контакт в Telegram.
В странице 12 полных роликов со звуком: 9 из канала и 3 личные истории.
Архивные поступления и цены относятся к дате записи, текущие условия обсуждаются
с Юрой. Текст между роликами — редакторская переработка, не дословная переписка.
Сайтовой формы нет.
Переходы по странице мягкие и учитывают настройку сокращения движения.

Крупные надписи набраны Oks Free Ильи Жерикова и сохранены готовой векторной
графикой. Файл Oks здесь не распространяется. Golos Text включён с лицензией OFL.

реальным положениям реплик. Он раскрывается при прокрутке; сокращение движения
показывает всю нить неподвижно. Контент и постеры не анимируются.

Это сравнение с основной версией, не её замена и не публикация.

с клавиатуры. Все 12 роликов оставались на паузе с временем 0, 11 VTT загрузились.
Режим без движения проверен локальным переключателем; системная эмуляция
reduced motion и системные 200% текста не проводились.
Снимки, свидетельства и ограничения: docs/reviews/2026-10-15-dialogue-thread/README.md.
